# 청년회 교제록

생명선앱스(api.jbch.org) API로 만드는 청년회 교제록 웹앱입니다.
GitHub `main`에 머지하면 Cloudflare Pages가 자동 배포합니다.

## 화면
| 메뉴 | 하는 일 |
|---|---|
| 모아보기 | 교제록 목록(월별로 묶음)·상세, 검색, 월 선택 |
| 기도제목 | 모든 교제록의 기도제목을 사람별·주차별로 모아보기 |
| 참석 흐름 | 주별 참석 인원 그래프, 최근 8주 출석표 |
| 작성 | 양식 작성 → **제목/본문 복사** → 교회 사이트 게시판에 붙여넣기, 사진 자동 축소, 작성 담당 순번 |
| 설정 | 청년회 명단, 작성 순번, **API 연결 확인**(파라미터 시험) |

게시판 API가 아직 연결되지 않으면 **예시 데이터**로 화면을 보여줍니다.

## 파일 구조
```
index.html              화면 틀
assets/style.css        디자인 (Pretendard 글꼴, 다크 모드 지원)
assets/app.js           화면 동작
assets/config.js        ★ 게시판 번호·파라미터 이름 설정 (API 확정 후 여기만 수정)
assets/sample.js        예시 교제록
functions/api/jbch.js   api.jbch.org 중계 함수 (/api/jbch)
```

## Cloudflare Pages 설정 (처음 한 번)
1. Cloudflare → Workers & Pages → 만들기 → Pages → Git 연결 → 이 저장소 선택
2. 빌드 설정: 프레임워크 **없음**, 빌드 명령 **비움**, 출력 디렉터리 **/** (또는 비움)
3. 설정 → 환경 변수 → `JBCH_TOKEN` 추가 (값: 발급받은 50자리 토큰, "암호화" 선택)
4. 다시 배포

토큰은 코드에 들어가지 않고, 중계 함수가 서버에서만 사용합니다.

## 교제록 본문 양식
작성 화면이 만드는 본문은 아래 모양이고, 모아보기는 이 `■ 제목` 줄을 읽어 참석자·기도제목을 뽑습니다.
```
■ 날짜: 2026.11.08 (일)
■ 작성: 홍길동
■ 참석자 (5명): 김가람, 이나래, ...
■ 말씀: 요한복음 15:5
요약...
■ 나눔
...
■ 기도제목
- 김가람: ...
■ 번개 후기
...
```
양식 없이 쓴 옛날 글은 원문 그대로 보여줍니다.

## 개인정보
API로 받은 회원·게시글 정보는 화면에서만 쓰고 저장하지 않습니다.
명단·작성 순번·작성 중인 글은 사용하는 기기(브라우저)에만 저장됩니다.
