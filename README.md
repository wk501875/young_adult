# 일산교회 청년회

생명선앱스(api.jbch.org) API로 만드는 일산교회 청년회 커뮤니티 웹앱입니다. 지금은 교제록·기도제목부터 시작해요.
GitHub `main`에 머지하면 Cloudflare Pages가 자동 배포합니다.

## 화면
| 메뉴 | 하는 일 |
|---|---|
| 로그인 | 깨사모 아이디로 로그인해야 들어갈 수 있음 (회원 전용) |
| 교제록 | 청년회교제실 글 목록(월별·부서별)·상세(사진·댓글 읽기·달기·내 댓글 지우기), 검색, 이전 글 더 불러오기 |
| 일정 | 월정표: 교회 전체·청년회·부서 일정을 한 달 달력과 목록으로, 거르기 칩, 이달 주제·안내·원본 그림. 관리자는 추가·고치기·여러 개 붙여넣기 |
| 관리 | (최고 관리자) 부서 목록, 부서 관리자 아이디, 부서 명단 |
| 기도제목 | 최근 교제록의 기도제목을 사람별·주차별로 모아보기 |
| 참석 흐름 | 주별 참석 인원 그래프, 최근 8주 출석표 (부서별로 골라 보기) — **관리자만** |
| 쓰기 | 부서 고르기 → 부서 명단에서 참석자 체크 → **게시판에 바로 올리기**(로그인 시) 또는 제목/본문 복사, 사진 자동 축소 |
| 내 정보 | 내 계정·로그아웃, 화면 밝기, (관리자만) API 연결 확인 |

청년회교제실은 **회원 전용 게시판**이라 첫 화면이 로그인 화면이고, 로그인해야 교제록에 들어갈 수 있습니다.
API 자세한 내용은 [docs/jbch-api.md](docs/jbch-api.md)에 정리했습니다.

## 디자인
- 방향: 커뮤니티 앱 (Creator Connect 참고) — 위쪽 검색·"교제록 쓰기", 부서 카드 줄, 환영 카드, 큰 사진 글 카드, 오른쪽 달력.
- 색: 선명한 파랑이 주 색, 교회 그림의 하늘색·남색·노랑을 보조로.
- 로그인 화면 배경은 교회 그림: `assets/church.png` (또는 .jpg/.webp) 파일을 넣으면 자동으로 써요. 없으면 하늘 그림.
- 기본은 밝은 화면. 내 정보 → 화면 밝기에서 바꿀 수 있어요.
- 편의 기능: 새 글 배지, 단계 표시(쓰기), 처음 한 번 안내(코치마크), 말풍선 도움말, 자동 저장 표시, 되돌리기 알림, 확인 창·바텀시트, 빈 화면 안내, 댓글 바로 보이기, 사진 크게 보기, 달력으로 날짜 고르기, 목록 위치 기억.

## 파일 구조
```
index.html              화면 틀
assets/style.css        디자인 (Pretendard 글꼴, 다크 모드 지원)
assets/app.js           화면 동작
assets/config.js        ★ 게시판 번호·파라미터 설정 (게시판이 바뀌면 여기만 수정)
functions/api/jbch.js   api.jbch.org 중계 함수 (/api/jbch) — 로그인·목록·댓글·글쓰기·사진 올리기
docs/jbch-api.md        생명선앱스 게시판 API 정리 (실제 응답으로 확인)
```
중계 함수는 글쓰기·사진 올리기·댓글 달기를 **청년회교제실(2122)에만** 허락합니다.

## Cloudflare Pages 설정 (처음 한 번)
1. Cloudflare → Workers & Pages → 만들기 → Pages → Git 연결 → 이 저장소 선택
2. 빌드 설정: 프레임워크 **없음**, 빌드 명령 **비움**, 출력 디렉터리 **/** (또는 비움)
3. 설정 → 환경 변수 → `JBCH_TOKEN` 추가 (값: 발급받은 50자리 토큰, "암호화" 선택)
4. 다시 배포

토큰은 코드에 들어가지 않고, 중계 함수가 서버에서만 사용합니다.

### 월정표 저장소 (Cloudflare KV)
일정은 Cloudflare KV 에 저장해요. Pages 프로젝트 → 설정 → 바인딩 → KV 네임스페이스, 변수 이름 **`CAL`** (운영·미리보기 둘 다).
- 최고 관리자(`ADMINS`): 교회 전체·청년회 일정, 이달 정보, 관리 화면(부서·부서 관리자·명단)
- 부서 관리자(관리 화면에서 지정): 그 부서 일정만 올리고 고침
- 회원: 교회 전체·청년회 + 명단에 이름이 있는 부서 일정만 봄 (다른 부서 일정은 안 보임)
- 부서 명단은 관리 화면에서 고치는 게 우선이고, 비어 있으면 환경 변수 `ROSTERS`를 써요.

### 관리자·부서 명단 (Cloudflare 환경 변수)
저장소가 공개라서 사람 이름은 코드에 넣지 않고 Cloudflare 환경 변수에 둡니다. 바꾼 뒤에는 다시 배포해야 반영돼요.

| 이름 | 종류 | 값 예시 | 하는 일 |
|---|---|---|---|
| `ADMINS` | 텍스트 | `wk5018,hong123` | 깨사모 아이디(쉼표로 구분). 이 사람만 **참석 흐름**이 보여요 |
| `ROSTERS` | 비밀(Secret) | `{"순종부":["김민수b","이다정s"],"사랑부":["…"]}` | 부서별 명단. 작성 화면에서 부서를 고르면 그 명단에서 참석자를 체크해요 |

- 명단은 **로그인한 회원에게만** 내려가고, 기기에 저장하지 않아요.
- 부서 명단이 없으면 설정의 "이 기기 명단"을 쓰거나 이름을 직접 적어요.
- 작성 화면에서 부서를 고르면 글 제목이 게시판 모양대로 `[2026 순종부] 2026.11.07 토요교제`로 만들어져요.

## 교제록 본문 양식
작성 화면이 만드는 본문은 아래 모양이고, 모아보기는 이 `■ 제목` 줄을 읽어 참석자·기도제목을 뽑습니다.
```
■ 날짜: 2026.11.08 (일)
■ 작성: 홍길동
■ 참석자 (5명): 김가람, 이나래, ...
■ 말씀: 요한복음 15:5
요약...
■ 나눔
...
■ 기도제목
- 김가람: ...
■ 번개 후기
...
```
게시판에서 쓰던 `[ 참석 B S ]` / `[ 기도부탁 ]` 양식도 읽어서 참석자·기도제목을 뽑습니다
(이름 뒤 형제 `b`, 자매 `s` 표시는 떼고 이름만 씁니다). 이 글들은 원문 그대로 보여주고, 위에 참석자만 정리해 둡니다.

## 개인정보
API로 받은 회원·게시글 정보는 화면에서만 쓰고 저장하지 않습니다.
로그인할 때 비밀번호는 저장하지 않고, 로그인 확인값(hash)만 그 기기에 남습니다. 로그아웃하면 지워집니다.
명단·작성 중인 글은 사용하는 기기(브라우저)에만 저장됩니다.
